## 03-oop

One file per problem. Run any file with `python3 <file>.py`.

**Operator overloading** (`operator_overloading/`)
- `p1_complex.py`: complex numbers, `+` and `-`
- `p2_person_comparison.py`: compare persons by age with `>`
- `p4_vector_dot_product.py`: dot product with `*`
- `p5_circle_comparisons.py`: all six comparison operators
- `p6_point2d_distance.py`: comparison by distance to the origin, `@total_ordering`
- `p7_matrix_multiplication.py`: matrix product with `*`, dimension check

**Inheritance** (`inheritance/`)
- `p1_vehicle.py`: Vehicle / Car / Bicycle, method overriding and polymorphism
- `p2_person_student_employee.py`: Person / Student / Employee, `super()`
- `p3_bank_account.py`: BankAccount / SavingsAccount, deposit, withdraw, transfer, interest
